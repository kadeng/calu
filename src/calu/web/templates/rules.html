Rules

Checked before any model is asked. A step that matches a deny rule waits for you; one that matches an allow rule and no deny rule runs without a model call; everything else goes to a checker. One regular expression per line, matched anywhere in the text (anchor with ^ and $); a # comment line directly above a pattern is kept as that rule's comment. Saving replaces the whole list, the same as calu rules edit, and a pattern that does not compile changes nothing.
